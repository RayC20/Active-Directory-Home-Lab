# Active Directory Home Lab

## Overview
This project is a hands-on Active Directory home lab that I built using Windows Server in a virtual machine. The goal was to practice common IT support and system administration tasks in a Windows domain environment.

## Technologies Used
- Windows Server
- Active Directory Domain Services (AD DS)
- Group Policy
- VMware Workstation
- Windows File Sharing

## What I Did
- Installed and configured Windows Server in a virtual machine
- Set up Active Directory Domain Services
- Created organizational units (OUs)
- Created and managed users and security groups
- Created an HR shared folder
- Configured folder sharing and user/group permissions
- Used Group Policy to manage domain settings
- Practiced basic Active Directory administration and troubleshooting

## Skills Demonstrated
- Active Directory Administration
- User and Group Management
- Group Policy
- Windows Server
- File and Folder Permissions
- Virtual Machines
- IT Support & Troubleshooting
